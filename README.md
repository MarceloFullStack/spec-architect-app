## O que é?

Uma bancada visual de desenvolvimento orientado a especificações (Spec-Driven Development) para agentes de IA. Você planeja a mudança, revisa os documentos e entrega tarefas de escopo fechado ao agente, com tudo versionado no Git:

`Ideia → Proposta → Requisitos → Tarefas → Agente → Verificação`

## Para quem é?

Para quem já programa com agentes de IA e quer menos retrabalho: em vez de corrigir a IA num chat longo, você define antes o que deve ser feito e verifica a implementação contra a especificação.

## Com quais agentes funciona?

Claude Code (`claude`), Codex (`codex`), Cursor Agent (`cursor-agent`), Kiro (`kiro-cli`) e Antigravity (`agy`). Tenha pelo menos um instalado e logado: o agente roda no console do app.

## Precisa de conta ou servidor?

Não. O app roda na sua máquina e os arquivos ficam no seu repositório. Node.js e a CLI do OpenSpec já vêm dentro do app. Git é opcional (habilita o painel de alterações).

## É gratuito?

Sim. **Spec Architect Community Edition — Free Forever.**

## É o OpenSpec?

Não, mas é compatível com ele e usa de propósito os mesmos nomes de pastas e arquivos: um projeto começado no OpenSpec continua aqui, e um começado aqui continua no OpenSpec, sem conversão. É um projeto independente, sem vínculo com a Fission AI. [OpenSpec](https://github.com/Fission-AI/OpenSpec) é um projeto de código aberto (licença MIT) da Fission AI.
