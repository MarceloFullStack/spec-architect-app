Sobre Spec Architect

Spec Architect é uma GUI visual para OpenSpec, a ferramenta de workflow spec-driven para agentes de IA como Claude Code, Cursor, Gemini CLI e outros.

Desenvolvido por Marcelo Guimarães, Spec Architect transforma a forma como equipes trabalham com especificações e desenvolvimento orientado por agentes de IA.
